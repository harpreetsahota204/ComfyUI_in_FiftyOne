# ---------------------------------------------------------------------------
# FiftyOne ComfyUI Plugin requirements
#
# The plugin core only talks to ComfyUI over its REST API, so its sole hard
# dependency is an HTTP client. We deliberately do NOT install the ML stacks
# for the optional detection / segmentation packs here — those are not bundled
# and would otherwise pull ~2-4 GB of weights/runtimes onto every machine,
# whether or not the user wants them.
#
# Optional packs (install via ComfyUI Manager if you want the Detection /
# Segmentation starter templates — see README "Optional detection /
# segmentation packs"):
#   - ComfyUI-Grounding  (object detection)    -> brings transformers, timm,
#                                                  einops, ultralytics, peft,
#                                                  huggingface_hub, ...
#   - ComfyUI-SAM3       (segmentation)         -> brings comfy-env, which
#                                                  manages SAM3's heavier deps
# ComfyUI Manager installs each pack's own requirements.txt into the ComfyUI
# environment, so there's nothing to declare here.
# ---------------------------------------------------------------------------
