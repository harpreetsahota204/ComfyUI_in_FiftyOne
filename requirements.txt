# ---------------------------------------------------------------------------
# FiftyOne ComfyUI Plugin requirements
#
# This file unions the runtime requirements of:
#   - the plugin itself (HTTP client for ComfyUI's REST API)
#   - vendored ComfyUI-Grounding (object-detection node pack)
#   - vendored ComfyUI-SAM3      (segmentation node pack, incl. interactive)
#
# The vendored packs ship under comfyui-plugin/vendor/ and get symlinked
# into ComfyUI's custom_nodes/ at panel startup; their dependencies must
# therefore be installed in the SAME Python environment that runs ComfyUI.
#
# First-time install pulls ~2-4 GB of ML weights/runtimes (transformers,
# ultralytics, sam2/sam3 deps via comfy-env, etc.) and may take a few
# minutes. flash-attn is NOT installed automatically; it's optional and
# only speeds up Florence-2 / SA2VA inference.
# ---------------------------------------------------------------------------
